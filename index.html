导入时间线

点击「导入文件」或把文件拖入页面。文件在本机浏览器中解析。

Chrome Trace

支持包含阶段事件与资源计数器的 .json 和 .json.gz。可直接选择合并后的阶段与资源时间轴。导入后可手动匹配自定义计数器和单位。

完整采集 CSV

同时选择同一次采集的 resources.csv 与 phases.csv，也可加入 manifest.json。CPU 核数用于把进程占用换算为百分比。

通用 JSON

time、start、end 以采集启动为零点，单位为秒。CPU / GPU 用百分比，内存用 GiB，存储和 PCIe 速率用 MiB/s。缺测可以省略或填 null。

{
  "samples": [
    {"time": 0, "cpu": 12, "gpu": 0, "rss": 1.5},
    {"time": 1, "cpu": 28, "gpu": 65, "rss": 2.1}
  ],
  "stages": [
    {"id": "prompt.encode", "start": 0, "end": 1}
  ]
}
